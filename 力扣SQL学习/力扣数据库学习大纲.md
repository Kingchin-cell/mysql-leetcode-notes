## 单元 0 · 先搞懂判题规则（30 分钟，不刷题）

- 力扣用 **MySQL 8.0**，只写一条 `SELECT`（少数题要 `UPDATE` / `DELETE`）
- 结果**列名必须和题目输出示例完全一致**，行顺序通常不敏感
- 判题只看结果集，不看写法优劣 → **先求对，再求简**
- 知道在哪看官方题解和"相关标签"（标签就是知识点地图）
- **判题通过 ≠ 写对了**：测试数据碰巧没覆盖的错法也会通过（如 `LENGTH` 代替 `CHAR_LENGTH`）

**准备**：把 `教学.md` 附录 B 的建表脚本在本机 MySQL 里跑一遍。

## 学习方法（3 条，照做效率翻倍）

1. **15 分钟卡点就砍**：卡住 15 分钟立刻看题解，看完**关掉**题解默写一遍，写不出来再看。宁看 3 遍不硬耗 1 小时。
2. **二刷只看错题**：每单元做完 3 天后，把错题重写一遍（不看答案）。一周内两次通关才算会。
3. **归类而不是记题**：做完一题，在错题本上写一句"这题属于 ___ 模板"。积到 20 条，你会发现 Medium 就那么几种。

## 六个必背模板

| 模板 | 代表题 | 关键写法 |
|---|---|---|
| 每组 Top-N | 184、1070 | `DENSE_RANK() OVER (PARTITION BY ... ORDER BY ...)` + 外层过滤 |
| 第 N 高 / NULL 兜底 | 176、177 | 外层包一层子查询，没结果时返回 NULL |
| 反连接（找不存在） | 183、607、577、1978 | `LEFT JOIN ... WHERE 右表.id IS NULL` |
| 行转列 | 1179、1193、1693 | `SUM(CASE WHEN ... THEN x END)` + `GROUP BY` |
| 列转行 | 1795、602 | 多段 `SELECT ... UNION ALL` |
| 留存率 / 比率 | 550、1211、1251、1934 | 分子分母分别 `COUNT(DISTINCT ...)` 再相除 |
