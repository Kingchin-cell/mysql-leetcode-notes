## 怎么用

### 1. 准备数据库

```bash
mysql -u root -p
```

```sql
CREATE DATABASE IF NOT EXISTS learn_sql DEFAULT CHARACTER SET utf8mb4;
USE learn_sql;
-- 然后把教程「附录 B」的建表脚本整段粘贴执行
SELECT * FROM employee;
```

> 需要 **MySQL 8.0+**（用到窗口函数、CTE）。SQLite 不适用：日期函数、窗口帧语法都有差异。

### 2. 开始学

打开 `教学.md`，按第 0 → 11 章顺序走。每章结构统一：

```
① 什么时候用 → ② 语法模板 → ③ 可运行例子 → ④ 坑 → ⑤ 自测
```

自测答案默认折叠，先自己写，再点开对答案。

### 3. 开始刷题

学完前 7 章后打开 `力扣数据库学习大纲.md`，按单元顺序刷，题号直接搜力扣。

## 示例数据的设计意图

教程附录 B 的示例表是**故意构造**的，用来暴露常见陷阱：

| 数据 | 用来演示 |
|---|---|
| 某员工 `dept_id` 为 NULL | LEFT JOIN / IS NULL / `<>` 漏行 / ORDER BY 的 NULL 位置 |
| 两人工资都是 15000 | `RANK` vs `DENSE_RANK` vs `ROW_NUMBER` |
| 有个部门没人 | LEFT JOIN 反连接 |
| 有个客户没下单 | NOT IN / NOT EXISTS |
| 邮箱表里有重复值 | GROUP BY + HAVING 找重复 |
| 订单有 cancel 状态 | 条件聚合（占比、取消率） |

## 六个必背模板

| 模板 | 代表题 | 关键写法 |
|---|---|---|
| 每组 Top-N | 184、1070、1532 | `DENSE_RANK() OVER (PARTITION BY ... ORDER BY ...)` + 外层过滤 |
| 第 N 高 / NULL 兜底 | 176、177 | 外层包一层子查询，没结果时返回 NULL |
| 连续区间 | 1285 | `值 - ROW_NUMBER()` 作为恒定分组键 |
| 行转列 | 1179、1193 | `SUM(CASE WHEN ... THEN x END)` + `GROUP BY` |
| 列转行 | 1795、602 | 多段 `SELECT ... UNION ALL` |
| 留存率 / 比率 | 550、1211 | 分子分母分别 `COUNT(DISTINCT ...)` 再相除 |

## 学习方法

1. **15 分钟卡点就看题解**：看完关掉题解默写一遍，写不出来再看。
2. **二刷只看错题**：做完 3 天后重写错题，一周内两次通关才算会。
3. **归类而不是记题**：每做完一题记一句「这题属于 ___ 模板」，积累 20 条就能看穿大部分 Medium。
